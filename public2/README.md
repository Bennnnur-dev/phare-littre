# Projet Harcèlement

Application web de gestion de formulaires et d'authentification en Node.js avec Express, EJS et Passport.

## Démarrage

Installer les dépendances :

```bash
npm install
```

Lancer le serveur :

```bash
npm start
```

## Fichiers importants

- `server.js` : serveur Node.js
- `scripts/` : scripts côté serveur et configuration
- `styles/` : styles CSS
- `index.html`, `connexion.html`, `formulaire.html`, `register.html`, `reception.html` : pages front-end
- `.env` : variables d'environnement (ne pas committer)
